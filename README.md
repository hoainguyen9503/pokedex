# Pokédex Việt Nam

Website Pokédex tiếng Việt với 1.025 Pokémon và các dạng biến thể, hình ảnh từ
Cổng Pokémon chính thức Việt Nam, tìm kiếm, lọc theo 18 hệ và xem thông tin chi
tiết.

## Chạy cục bộ

```bash
npm install
npm run dev
```

## Triển khai

Mỗi lần cập nhật nhánh `main`, workflow `Deploy GitHub Pages` sẽ tự build và
triển khai website tại:

https://hoainguyen9503.github.io/pokedex/

Trạng thái: GitHub Pages đã được cấu hình với GitHub Actions.

Pokémon và tên Pokémon là thương hiệu của Nintendo / Creatures Inc. /
GAME FREAK inc.
